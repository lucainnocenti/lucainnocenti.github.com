# Luca Innocenti — personal website

A static site: open `index.html` in a browser to preview it. No build tools are needed. Edit `index.html` for content and `style.css` for the design.

The Notes & Explorations section is reserved for future articles and interactive visualizations. Each can be added as its own directory with an `index.html` and linked from the home page. Relative asset links keep the site suitable for GitHub Pages, including a project subpath.

The local changes are not published until committed and pushed and GitHub Pages is configured for the repository.

The publication list loads public journal articles and preprints from ORCID on each visit, excluding corrections and conference material. A saved list in index.html is shown when ORCID is unavailable. The supplemental list near the top of publications.js contains preprints not yet in ORCID; add new preprints to ORCID or update that list.
